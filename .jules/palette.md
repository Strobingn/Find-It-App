## 2025-02-14 - Stepper buttons with symbol text in Compose
**Learning:** Stepper buttons or icon buttons displaying raw symbols or unicode characters (e.g. `Text("–")` or `Text("+")`) inside `IconButton` lack meaningful semantic announcements for screen readers (which read them literally as "minus" or "dash" and "plus" without context). Additionally, leaving steppers always enabled when values reach their valid boundaries (e.g. hour < 0 or > 23) causes dead taps and poor user feedback.
**Action:** When implementing numeric or step-based adjustments with text/symbol buttons, always add explicit `semantics { contentDescription = "..." }` (e.g., "Decrease hour", "Increase hour") and bind `enabled = ...` to the valid range limits so screen readers announce the semantic action and disabled state.
