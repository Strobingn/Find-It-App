## 2025-05-18 - Clear Action Verb Content Descriptions for Jetpack Compose Icon Buttons
**Learning:** Icon buttons with single noun labels like "Dig logs" or short verbs like "Send" can be ambiguous or lack action clarity for screen reader users in dense field tool views.
**Action:** Always use clear verb phrases for icon button `contentDescription`s (e.g. "Open dig logs", "Send message") when the icon button triggers an overlay, dialog, or action.
