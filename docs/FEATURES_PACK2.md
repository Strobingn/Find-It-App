# GROKV5 feature pack 2 (5 field finds features)

Built on top of pack 1 (`FEATURES_GROKV5.md`). Branch `GROKV5` only until merged.

| # | Feature | Description |
|---|---------|-------------|
| 1 | **Starred finds** | Star priority finds for return trips; chip filter "Starred only"; star persists in Room (v16). |
| 2 | **Proximity warning** | Mark/log warns if another find is within 8 m; user can cancel or log anyway. |
| 3 | **Nearest-find HUD** | On Terrain with GPS, shows distance + bearing to the closest georeferenced find. |
| 4 | **Find sort modes** | Sort list: Starred first · Newest · Nearest to device GPS. |
| 5 | **Copyable coordinate HUD** | Terrain HUD shows decimal lat/lon and a tap-to-copy action. |
